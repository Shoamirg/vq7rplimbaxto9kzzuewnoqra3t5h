# GarageOS agent guidance

## Agent skills

### Issue tracker

For plans, specs, and work tickets, use GitHub Issues in `Shoamirg/garageos`. Read `docs/agents/issue-tracker.md` before creating or updating issues.

### Triage labels

When triaging incoming issues, use the label roles in `docs/agents/triage-labels.md`.

### Domain docs

Before changing GarageOS domain concepts or recording architecture decisions, read `docs/agents/domain.md` and the relevant existing ADRs.
