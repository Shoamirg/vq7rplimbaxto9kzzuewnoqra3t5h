# Triage labels

Use these GitHub label strings for the five triage roles.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| Needs evaluation | `needs-triage` | Maintainer needs to evaluate the issue |
| Needs information | `needs-info` | Waiting on the reporter |
| Ready for an agent | `ready-for-agent` | Fully specified for agent implementation |
| Ready for a human | `ready-for-human` | Requires human implementation |
| Will not be done | `wontfix` | Closed without implementation |
