**GarageOS Dev**, package `uz.garageos.garageos_staff.dev`. API manzili
`http://10.0.2.2:8000/api/v1`; backendni [mahalliy yo‘riqnoma](../../docs/testing/android-local.md)
bo‘yicha ishga tushiring. O‘rnatilgan oddiy GarageOS bilan yonma-yon ishlaydi.

APK asosiy GitHub repo’ning Release assets bo‘limida saqlanadi. Backend-repo’da
APK saqlanmaydi. Mahalliy nusxa ham shu papkada, Git’dan tashqarida mavjud.

`11a5d46ddc35efa78bf809ce26640ea5205da229`. SHA256 va yig‘ilish ma’lumotlari:
[SHA256SUMS.txt](SHA256SUMS.txt), [build.json](build.json).
